HTML, CSS & JavaScript

The web platform is built on three complementary technologies. Each has a distinct job, and together they form the foundation of modern web development.

HTML

HTML

HTML (HyperText Markup Language) provides the structure of a web page, including paragraphs, links, images, and forms. It defines the content and organizes information.

CSS

CSS

CSS (Cascading Style Sheets) controls the visual presentation of HTML elements. It defines colors, spacing, typography, layouts, and animations.

JavaScript

JS

JavaScript adds interaction and dynamic behavior to websites. It allows developers to respond to user actions and update content.
